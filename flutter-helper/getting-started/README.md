# Flutter Helper getting started sample

This sample shows how to get started on building your search experience in Flutter with an infinite scroll pagination.

## Get started

Clone the getting started sample:

```sh
curl https://codeload.github.com/algolia/doc-code-samples/tar.gz/master | tar -xz --strip=2 doc-code-samples-master/flutter-helper/getting-started
```

Install dependencies:

```sh
flutter pub get
```

Run it on Google Chrome:

```sh
flutter run -d chrome
```
